Bank transfer by QR code for WooCommerce. Each order gets a VietQR code with the amount and order reference, accepted by most Vietnamese banking apps.

== Description ==

VietQR adds a "Bank transfer (scan QR code)" payment method to WooCommerce. For every order the plugin generates a VietQR code that already contains the bank account, the amount and a transfer memo with the order number. The customer scans it with their banking app and only needs to confirm the transfer, with no typing.

VietQR is the bank QR standard created by NAPAS and accepted by almost every banking app and e-wallet in Vietnam: Vietcombank, VietinBank, BIDV, Agribank, Techcombank, MBBank, ACB, VPBank, TPBank, MSB, MoMo, ZaloPay and more.

Features:

* New payment method: bank transfer by scanning a QR code, for both the classic checkout and the WooCommerce Checkout block
* Transfer memo built from a prefix and the order number, so the shop owner or reconciliation software can match payments easily
* QR code on the order received page and in the order email, with a "save QR image" button on mobile
* Bank list kept up to date automatically from VietQR.io
* Customisable template: copy `templates/bank-details.php` to `yourtheme/vietqr/bank-details.php`
* Only offered for orders in Vietnamese dong (VND)

The QR codes are generated by [VietQR.IO](https://www.vietqr.io).

== External services ==

This plugin connects to the following services operated by VietQR.io (https://www.vietqr.io):

* `api.vietqr.io` – downloads the list of supported banks (at most once per hour). Data sent: the site URL.
* `img.vietqr.io` – renders the QR code image shown on the order received page and in emails. Data sent: bank code, account number, account name, amount and transfer memo of the order.
* `vietqr.devgioi.com` – only when the shop owner enters a Developer ID in the settings. Data sent: the Developer ID and the site URL.

Terms of service and privacy policy: https://www.vietqr.io

== Frequently Asked Questions ==

= Which currencies are supported? =

VietQR codes are in Vietnamese dong, so the payment method is only shown when the store currency is VND. Developers can change this with the `vietqr_supported_currencies` filter.

= Can I choose which bank logos are shown at checkout? =

The checkout shows a few well known banks and a "+N other banks & e-wallets" tile. Use the `vietqr_featured_bank_bins` filter to return your own list of bank BIN codes.

= Does the plugin confirm payments automatically? =

No. Orders are put on hold until you confirm the transfer. The transfer memo contains the order number so it is easy to match.
